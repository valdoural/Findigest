# Финансовый дайджест — настольная версия для Windows

## Установка (для пользователя)

1. Запустите **FinDigest-Setup-0.10.2.exe**.
2. Windows может показать «Система Windows защитила ваш компьютер» — программа пока не подписана
   сертификатом. Нажмите **Подробнее → Выполнить в любом случае**.
3. Выберите, для кого ставить, и **папку установки** (по умолчанию — ваш профиль, права администратора не нужны).
4. После установки программа откроется сама и запустит **мастер первой настройки**:
   база данных → ИИ → Zenmoney → почта. Каждый шаг объясняет, что и зачем делаем; любой можно пропустить
   и подключить позже кнопкой со штекером в шапке отчёта.

Дополнительно ничего ставить не нужно: SQLite, шрифты и библиотеки уже внутри.

### Чеки из почты
«Подключения → Почта»: адрес, пароль приложения и магазины с адресами отправителей чеков. Кнопка «Сохранить и проверить почту»
сразу находит чеки, разбирает их и добавляет покупки в «Продукты». Дальше всё само: почта проверяется при запуске,
каждые 15/30/60 минут (настраивается) и по кнопке «Обновить» в шапке; новый чек разбирается без перезагрузки отчёта,
появляется подсказка «Новый чек из почты: магазин · дата · сумма». Для нового магазина письма ищутся на всю глубину
(по умолчанию 90 дней). Текстовые чеки (HTML, PDF с текстом) разбираются без ИИ, фото и сканы — с ИИ.

### Помощник
Кнопка с микрофоном в шапке или **Ctrl+Shift+Пробел** из любой программы: задайте вопрос голосом или текстом
(«сколько я потратил на продукты в сентябре?»). Для распознавания голоса нужен ключ Gemini, GPT или Groq; с ключом Claude — только текст.
Ответы озвучиваются **живым голосом**, если подключён один из сервисов (настройки помощника → «Озвучка ответов», по умолчанию «Авто»):
GPT (голоса Marin, Cedar и др.), Gemini (Sulafat, Kore, Charon…) или YandexGPT (SpeechKit: Алёна, Филипп, Ермил…; сервисному аккаунту
нужна роль на SpeechKit). Перед озвучкой текст приводится к виду «для слуха»: «₽» → «рублей», «12%» → «12 процентов», «млн» → «миллиона», «т.е.» → «то есть».
Без ключей — голос Windows (лучше всего звучат «естественные» голоса: Параметры → Время и язык → Речь → «Добавить голоса» → Русский).
При первом использовании Windows может спросить разрешение на микрофон.

### Выводы ИИ
На каждом листе — короткие выводы по вашим данным: что изменилось, почему и что проверить. Обновляются сами после
обновления данных (не чаще раза в 4 часа) или кнопкой «Обновить выводы». Отключить автообновление — «Подключения → ИИ».

### Оформление
Кнопка темы в шапке: светлая тема — исходный вид, тёмная — «Полночь». Отдельного выбора оформления больше нет.
Логотипы банков и магазинов подгружаются с их сайтов; если не найден — остаётся буква.
Поля дат открывают свой календарь (значок справа в поле, Alt+↓ или F4).

### О программе и обновления
«⋯ → О программе и обновления» (или «Подключения → О программе»): создатель, версия и обновление программы из GitHub.
Укажите репозиторий, где выпускаются версии (владелец/название), — программа проверяет новые версии при запуске и раз в 12 часов,
показывает подсказку «Доступна новая версия», скачивает установщик, сверяет контрольную сумму и ставит обновление поверх
(папка, данные и ключи сохраняются). В списке «Версии» — все выпуски со ссылками на релиз и исходники; можно и откатиться.
Токен GitHub нужен только для закрытого репозитория и хранится в secrets.json.

### Как считаются расходы
Как в Zenmoney: поступление в расходной категории (возврат за покупку, долг за кафе) уменьшает расход в день поступления;
перевод дальше денег, собранных в доходной категории (например, на день рождения), — не расход. Одно правило для всех графиков и сравнений.

### Регион и имущество
«Доходы и расходы → Вы, регион и РФ»: выберите субъект РФ из списка; кнопка «Найти данные» (и обновление выводов ИИ)
просит подключённый ИИ найти последние официальные цифры — зарплату, структуру трат — с источником и датой. Значения,
которые выглядят неправдоподобно, отбрасываются; где цифр нет — «нет данных».
«Имущество»: кроме квартиры можно добавить дом, машину, ещё квартиру, участок, гараж, коммерческую недвижимость и другое —
у каждого типа свои поля и своя оценка. Если объектов несколько, верхний блок показывает их общую сумму.

### Импорт квитанций и чеков из таблиц
CSV, TXT и XLSX (в том числе из Excel и файлы, выгруженные самим дайджестом): «Данные → Импорт из файла»,
кнопка «Таблица квитанций» в архиве ЖКХ или зона «Импорт чека» на листе «Продукты». Перед добавлением программа покажет,
что нашла; повторный импорт того же файла ничего не задвоит.

### Где что лежит
* программа — в выбранной папке;
* данные — `%APPDATA%\FinDigest\` (база, оригиналы чеков, настройки);
* **ключи и пароли — отдельным файлом** `%APPDATA%\FinDigest\config\secrets.json`, зашифрованы Windows.

При удалении программы данные остаются. Резервная копия — скопировать папку `%APPDATA%\FinDigest`
(ключи на другом компьютере придётся ввести заново: шифрование привязано к учётной записи Windows).

## Выпуск версии на GitHub

```
set GH_TOKEN=github_pat_…        (Fine-grained token: доступ к репозиторию, Contents: Read and write)
npm run release            (репозиторий по умолчанию — valdoural/findigest)
```
Собирает установщик и создаёт релиз vX.Y.Z (версия из package.json) с установщиком, latest.yml (sha512) и архивом исходников.
Все версии остаются в Releases; последняя — https://github.com/valdoural/findigest/releases/latest.
Репозиторий по умолчанию для программы — `fdRelease` в package.json (тогда обновления работают сразу после установки).
`--dry` — показать шаги без выпуска.
